Description: A Java console-based Task Management Application. The program helps manage tasks with scheduling, validation, and duplicate conflict checks.
Features: 
- ADD: Create new tasks with automatic ID increment, date validation, and time overlap prevention.
- DELETE: Remove an existing task by ID.
- Display: View all tasks formatted neatly in a structured table.
- Smart Validation: Validates input parameters including task types, name formats, and operating hours (8.0 - 17.5).
